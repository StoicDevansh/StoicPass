# StoicPass

A simple and modern password manager. Free forever, open-source.

## Installation

### Requirements
- Java 11+
- Gradle

### Setup

1. Clone the repository:
```bash
git clone https://github.com/StoicDevansh/StoicPass.git
cd StoicPass
```

2. Build the project:
```bash
./gradlew build
```

3. Run:
```bash
./gradlew run
```

## Usage

1. **Launch** the app
2. **Create** a master password (this encrypts all your passwords)
3. **Add passwords** - Click to save credentials
4. **Retrieve** - Search and autofill when needed
5. **Sync** - All data stays local and encrypted on your device

## Features

- ✅ End-to-end encryption
- ✅ No cloud storage (offline-first)
- ✅ No ads, no tracking
- ✅ Free forever
- ✅ Open source
